# 바람의나라 직업 효율 분석 프로젝트

## 🔍 분석 목표
- 뉴비가 시작하기에 부담이 적은 **효율적인 직업**을 찾아보기
- 직업별 능력치 성장 효율, 장비 착용률 등을 기반으로 다각적인 분석 수행

---

## 📌 데이터 구성 및 전처리

- **데이터 출처**: 넥슨 Open API
- **주요 컬럼**:
  - 캐릭터 정보: `job`, `character_level`, `character_exp` 등
  - 능력치: `힘`, `지력`, `지혜`, `건강`, `민첩`, `체력치`, `마력치`
  - 장비 슬롯: `무기`, `방패/보조무기`, `보조1`, `보조2`, `세트옷`, `신발` 등
- **전처리 작업**:
  - 필요 컬럼만 필터링
  - 직업별 상위 200명 추출
  - 경험치를 기준으로 순위 재정의

---

## 📊 주요 분석 내용

### 1. 직업별 상위 랭커 분포
- 상위 랭커 분포를 통해 **인기 직업과 비인기 직업** 파악

### 2. 직업별 평균 능력치
- 레벨 대비 능력치의 평균치를 직업별로 시각화
- 도사, 주술사, 차사 등 주요 직업에 집중

### 3. 스탯 효율 분석
- **스탯 효율** = 능력치 / 레벨
- 레벨 구간별로 능력치가 얼마나 상승하는지 라인 차트로 분석

### 4. 장비 슬롯 착용률 분석
- 각 직업의 장비 슬롯별 평균 착용률을 히트맵으로 시각화
- 특정 직업군에서 **장비 접근성이 낮은 슬롯** 파악

---

## ✅ 결론

- **도사**: 지혜 스탯 효율이 압도적으로 높으며, 전체적으로 안정된 곡선을 보임  
- **주술사**: 지력 기반 성장형으로, 후반에 민첩도 증가하는 특성을 보임  
- **장비 착용률**: 대부분 직업에서 90% 이상 유지되나,  
  - 주술사/살수 등의 방패/보조무기 착용률이 현저히 낮음 → 진입장벽 가능성
